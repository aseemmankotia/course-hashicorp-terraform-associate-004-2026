## Chapter 12: Full Practice Exam & 60-Minute Time-Management Strategy — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Roughly how much time do you have per question on the TA-004 exam (60 min / ~57 questions)? | About 1 minute per question. Exam tip: bank a 5-10 minute buffer at the end for flagged-question review by keeping pace near 1 min/question during the first pass. |
| 2 | List the question formats that can appear on the TA-004 exam. | Multiple choice, multiple response, true/false, fill-in-the-blank, and text-match. Exam tip: multiple response questions require ALL correct options selected — no partial credit. |
| 3 | What should you do with a question you're unsure about during the first pass? | Flag it and move on immediately rather than spending extra time. Exam tip: answer with your best guess before flagging so you never leave it blank. |
| 4 | When should you revisit flagged questions? | Only after every question in the exam has an answer. Exam tip: unanswered questions guarantee zero points; flagged-but-answered questions still count if time runs out. |
| 5 | count vs for_each — when to use which? | count: identical resources indexed numerically. for_each: resources keyed by a map or set of strings, avoiding index-shift issues when the list changes. Exam tip: inserting/removing an item mid-list with count can trigger destroy/recreate of unrelated resources. |
| 6 | What does the `moved` block do? | Declares that a resource's configuration address changed (rename/refactor) so Terraform updates state in place instead of destroying and recreating it. Exam tip: use this instead of manually editing the state file. |
| 7 | What does the `removed` block do (Terraform 1.7+)? | Declares that Terraform should stop managing a resource, with explicit control over whether the real infrastructure is destroyed (supports 'forget' without destroy). Exam tip: contrast with moved (rename) — removed drops management entirely. |
| 8 | Purpose of the .terraform.lock.hcl file? | Records exact provider versions and checksums selected during init, ensuring consistent provider versions across team members and CI. Exam tip: this file should be committed to version control. |
| 9 | Terraform Community Edition vs HCP Terraform — key difference? | Community Edition is the free, open-source local CLI. HCP Terraform (formerly Terraform Cloud) is HashiCorp's managed service adding remote state, remote runs, private registry, and policy-as-code (Sentinel) on top of the CLI. |
| 10 | What is checked during Certiverse remote-proctoring exam start? | Valid government-issued photo ID and a webcam room scan confirming a clear desk with no unauthorized materials. Exam tip: no printed notes, second monitors, or reference docs allowed, even out of camera view. |
| 11 | Final-day high-yield review list for TA-004 (name 4 topics). | count vs for_each indexing behavior, moved block for renames, removed block for forget-without-destroy, and the .terraform.lock.hcl provider lock file. Exam tip: these show up repeatedly across scenario and configuration questions. |
| 12 | Domain-weighted strategy for a final study pass — what should you prioritize? | Spend proportionally more review time on domains with the highest published exam weight percentages, then use remaining time on lightly-tested domains for quick reinforcement. Exam tip: don't spend equal time on every domain if weights are uneven. |

# Chapter 4 Lab: Core Workflow Part 1: Init, Validate, Plan

**Estimated time:** 20 minutes

## Exercise

Initialize a working directory with terraform init, run terraform validate against a config with a deliberate typo, fix it, then run terraform plan and interpret the +/-/~ symbols in the output

## Key takeaway

terraform init prepares the working directory, validate checks syntax only, and plan previews exactly what apply would change.

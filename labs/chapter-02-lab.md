# Chapter 2 Lab: Terraform vs Other IaC & Configuration Tools

**Estimated time:** 10 minutes

## Exercise

Read a short comparison table and match each tool description (Ansible, Terraform, a generic declarative provisioning tool) to its correct category: provisioning vs configuration management vs declarative vs procedural

## Key takeaway

Terraform provisions declaratively via an execution plan and state, and commonly complements (rather than replaces) configuration management tools.
